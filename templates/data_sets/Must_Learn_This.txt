I’ll structure this as a professional, English-only command reference covering Linux, Termux, PowerShell, and Bash, progressing from absolute beginner to advanced system administration and automation.

One important distinction: Linux commands and Bash commands overlap, but they are not identical. Termux is an Android terminal environment, while PowerShell has its own command system. The guide will explain each separately.

### Level 7 — Bash Automation

```bash
#!/usr/bin/env bash

SOURCE="$HOME/Documents"
BACKUP="$HOME/backup"

mkdir -p "$BACKUP"

    echo "Backup completed"
else
    echo "Source directory not found"
fi
```

### 07\. Important Safety Rules

* Never execute unknown shell scripts as root.

* Understand `rm -rf` before using it.

* Avoid running unverified commands copied from the internet.

* Review PowerShell execution policies before changing them.

* Never expose SSH private keys or credentials.

* Do not scan or access networks without authorization.

* Test destructive operations in a virtual machine or disposable environment first.

### 08\. Recommended learning order
